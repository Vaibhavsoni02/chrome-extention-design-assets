# Chrome Web Store Asset Generator

**Created:** 2026-07-11

## Problem
Creating Chrome Web Store icons and promotional images from a website is slow and repetitive.

## Solution
A Streamlit app that captures a site and generates store-ready icons/tiles as a downloadable zip.

## Outcome
Faster, consistent Chrome Web Store listing assets from a URL.
